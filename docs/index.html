財經日曆桌布

目前版本 v0.0 · Windows 10/11（x64 / ARM64）

時鐘、總經日曆、台股事件、行情條，拆成可各自擺放的桌面小工具，常駐系統匣。資料由程式內建抓取，不必另裝 Python，新版本自動更新。

⬇ 下載最新版（x64） GitHub 原始碼
手動選擇：x64 安裝檔 · ARM64 安裝檔 不確定？在「設定 → 系統 → 關於」的「系統類型」查看。ARM64 電腦（例如 Snapdragon 機種）請裝 ARM64 版，x64 版會一直以模擬方式執行。

📦 下載後執行安裝檔，依提示完成 — 不需系統管理員權限，裝好自動常駐系統匣，之後自動更新。

五套動態桌布

預設是「不接管」，桌布維持原樣；從系統匣開設定視窗選一套主題，才會換成動態桌布。所有螢幕用同一套主題，每台螢幕依自己的原生解析度各畫一張。隨時改回「不接管」，或從系統匣「結束」，就會還原原本的桌布（原桌布若是 Windows 焦點，需自行到 Windows 設定切回）。

以測試資料繪製，圖為桌布局部；實際畫面依你的螢幕與當天資料而定。

脊線

最前面那條金線，就是加權指數最後一個完整交易日的盤中走勢。

  • 60 條山脊由遠到近互相遮擋，只有最近的金線是真實資料，其餘是裝飾；金色只留給資料。
  • 時間對應橫軸，價格依當日高低點線性對應高度（呈現走勢形狀，不代表漲跌幅大小）；開盤前與收盤後以細虛線水平延伸，表示沒有資料。
  • 金線下方標示交易日。
  • 資料落後 3 個交易日以上時，右下角顯示「資料停在 M/D」。

等高線

把最後一個完整交易日的盤中走勢畫成一片山脊地形，價格越高地勢越高，最高處就在當日高點。

  • 琥珀色三角標出走勢的局部高點，旁邊的數字是該點的指數價位，不是示意值。
  • 深青底、每 5 條一條計曲線，外框是航海圖式刻度。
  • 左下標示交易日。
  • 資料落後 3 個交易日以上時，右下角顯示「資料停在 M/D」。

天際線

黃昏的城市，最前排 20 棟樓就是加權指數最近 20 個交易日的日 K。

  • 樓身高到 K 線實體上緣，天線是上影線；收盤高於開盤樓頂亮紅邊，低於開盤亮綠邊。
  • 一條冷藍電線串起每根 K 的 20 日均線。
  • 紅、綠、冷藍只用在資料上；台北 101、遠山與後排樓群是裝飾。
  • 左上標示日期範圍、最新一根的收盤價與 20MA；資料落後 3 個交易日以上時，右下角顯示「資料停在 M/D」。

撕日曆

一本撕頁黃曆，「宜」「忌」寫的是台股的日子。

  • 本機當天的日期、星期與干支年。
  • 「宜」依序看：休市日（固定「出去走走　陪陪家人」）、台積電法說會當日、財報密集週、旺季月份（預設 7–9 月電子旺季、10 月年底備貨）。
  • 「忌」：休市日是「懊悔無賣高買低」「輸錢怨氣帶回家」；交易日上市券資比低於 2% 或融資維持率低於 150% 時，是「借錢加碼」（融資資料過舊時不採用）。
  • 其他日子從詞庫取一句，同一天固定同一句；詞庫與門檻都能在主題設定檔修改。

星盤

24 小時的盤面，六個市場一圈一圈排開：現在誰在交易、接下來輪到誰。

  • 東京、首爾、台北、香港、倫敦、紐約各一條環；「現在」固定在正上方，盤面隨時間轉動，畫出前 10 小時到後 12 小時。
  • 粗線是現貨正規交易，外側細線是盤前／盤後，內側虛線是指數期貨夜盤或延長交易。
  • 每條環標出目前狀態（交易中、盤前、夜盤、休市⋯），盤心列出接下來最多四筆開盤或收盤時刻。
  • 依本機時區顯示、夏令時間自動換算；休市日整條環變暗並寫出假日名。

特色

  • 五個獨立小工具

    時鐘・總經日曆・台股固定事件・台股動態事件・行情條，各自一個視窗、可各自開關、拖曳擺放；清單直接用滑鼠滾輪捲動。

  • 48 格線版面

    每個螢幕的工作區切成 48×48 格線記錄位置與大小。編輯版面時可拖曳移動、調整大小，放開對齊格線，重疊就彈回。

  • 多螢幕與 DPI

    版面依各螢幕工作區記錄，小工具可放在任一台螢幕，不同縮放比例（DPI）的螢幕之間定位正確。

  • 總經日曆

    Forex Factory 美國・歐元區・日本中高重要性事件，含預測/前值，跟隨系統時區顯示。

  • 台股事件

    市值前百大財報公布日・法說會・股東會預告＋處置股（當日制、遇休市順延）；另列台指期結算、財報與月營收截止等固定事件。

  • 行情條

    13 檔跑馬燈：加權・台積電・道瓊・費半・SOFR…，紅漲綠跌。

  • 動態桌布

    五套主題（脊線・撕日曆・星盤・等高線・天際線）定時重畫（脊線、等高線、天際線依加權指數資料，撕日曆依休市日、融資與財報事件），每台螢幕依原生解析度設成 Windows 桌布。預設「不接管」；改回「不接管」或從系統匣結束時還原原桌布（Windows 焦點需自行切回）。

  • 資料內建抓取

    不需 Python、不需排程。台北時間每日 00・06・12・15・18 點抓取，程式啟動或睡眠恢復時錯過就補抓；單一來源失敗沿用上一份資料。

  • 自動更新

    每 6 小時檢查新版，背景下載並驗證簽章後於系統匣通知；點選單即可立即更新；登入後 10 分鐘內就備妥的新版會自動安裝。

  • 不掛進 explorer

    小工具是獨立的置底視窗，不嵌入 explorer 的視窗樹；explorer 重啟後自動重新置底。全螢幕、鎖定時暫停動畫。

  • 深色半透明外觀

    深色半透明純色背景與圓角，透明度與主題色可在設定視窗調整。

安裝

  1. 下載安裝檔（上方按鈕會依電腦架構選擇；也可手動選 x64 或 ARM64）。
  2. 執行安裝檔，依提示完成。不需系統管理員權限，裝在你自己的使用者資料夾；缺少 WebView2 執行階段時會自動下載安裝。
  3. 安裝完成後程式自動啟動，出現在系統匣；之後每次登入 Windows 自動啟動（可在設定視窗關閉）。小工具開關、版面與桌布主題都從系統匣開設定視窗調整。
  4. 之後自動更新，不需再回來下載。

⚠ 安裝檔目前沒有程式碼簽章

執行時 Windows 可能顯示 「Windows 已保護您的電腦」：點 「其他資訊」，再按 「仍要執行」。未簽章的檔案每個新版本都要重新累積信譽，手動下載新版時可能再看到這個警告。

開著「智慧型應用程式控制」（Smart App Control）的電腦可能直接擋下，而且沒有「仍要執行」，詳見 README。請只從本專案的 GitHub Releases 下載。

解除安裝：在「應用程式與功能」移除「財經日曆」，會先還原原本的桌布（Windows 焦點需自行切回）。完整說明見 README。
