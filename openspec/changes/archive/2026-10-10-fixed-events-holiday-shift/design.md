## Context

`host/ui/widgets/fixed.js` 是從 Lively 版原樣搬來的純本地計算：`fixedOccurrences(13)` 從本月起逐月產生四類事件，`fullRender()` 依「本週」（週日–週六）切成本週清單與每類「下一次」，`updateTimeSensitiveState()` 每 60 秒原地切換 `past` 與「今天」徽章、跨週才整份重建。它訂閱 `tw-events` 通道但完全不讀資料。

可用的資料與工具：

- `tw_events.json` 的 `holidays`：TWSE holidaySchedule，`YYYY-MM-DD` 字串陣列，**只有當年度**；已排除「開始／最後交易日」說明列，保留「市場無交易，僅辦理結算交割」日（AGENTS.md「資料來源細節」）。
- `common.isTradingDay(d, holidays)`：非週末且不在 `holidays` 集合內；台股動態事件的處置股順延已在用。

規則查證（2026-10-10，一手來源）：

- 台指期／選擇權：期交所 TX／TXO 契約規格「最後交易日若為假日或因不可抗力因素未能進行交易時，以其最近之次一營業日為最後交易日」。2026-02 實例：第三個週三 2/18 在春節內，最後結算日為 2/23；春節前「僅辦理結算交割」的 2/12、2/13 未被當成結算日——與 `holidays` 的判定一致。
- 財報（證交法第 36 條第 1 項第 1、2 款）、月營收（同項第 3 款）：條文無順延字句。金管會 2024-02 新聞稿把 3/31（週日）的年報期限寫成 4/1；月營收另有主管機關「公告延長」機制（例如 2022、2023 連假），但 2025 年春節明說不延長。
- 季結算第三個週五：只有美股指數期貨（CME NQ／YM；期交所 UNF／UDF）。期交所美股期貨遇我國假日是**提前**，CME 依美國假日處理；台股季月結算是第三個週三。

## Goals / Non-Goals

**Goals:**

- 三類台灣事件以順延後日期參與本週／下一次／已過去／今天的所有判斷，並以徽章標出原日期。
- 順延計算是可在 Node 單獨測試的純函式。
- 資料晚到或更新時不打斷使用者的捲動位置，除非休市日真的變了。

**Non-Goals:**

- 金管會臨時「公告延長」的期限（沒有可機讀來源）。
- 美股季結算的美國假日調整（需要美國休市日曆，本專案沒有）。
- Q2 財報 8/31 的金融業／第一上市（櫃）例外、年報 3/16 的大型公司例外（列 Backlog）。
- 補抓跨年度休市日（資料層只取當年度）。

## Decisions

### D1 順延規則與日曆

三類台灣事件一律「原日期不是交易日 → 往後找第一個交易日」，交易日用 `common.isTradingDay` 與 `holidays` 集合，不分事件另設日曆。

- 台指期是交易所規則，「營業日」從 2026-02 實例看就是交易日曆。
- 財報與月營收的「上班日」理論上是行政機關辦公日，與交易日只在少數日子不同（春節前僅結算交割日、颱風假）。差異日幾乎不會剛好是 10 日或財報截止日，且本來就是推定，以徽章說明交代；不為此另抓行政機關行事曆。
- 季結算維持不調整：套台灣休市日順延，方向與期交所（提前）和 CME（依美國假日）都不同，比不調整更錯。

替代方案：月營收不調整、只標「休市」——使用者 2026-10-10 選了推定順延（對話選項 A）。

### D2 純函式放在 `common.js`

新增 `common.nextTradingDay(d, holidays)`：`d` 是交易日就回傳 `d`（同一個時間值），否則逐日往後找，上限 30 天（同 `targetDay`，理論上不會走到；走到時回傳原日期、不順延）。`targetDay` 改為呼叫它，行為不變。

`fixedOccurrences` 抽成 `common.fixedOccurrences(today, holidays, monthsAhead)`，每筆回傳 `{ date, orig, tag, label, note }`：`date`＝顯示日期，`orig`＝原日期（未順延時與 `date` 相同），`note`＝徽章說明（未順延時為 `null`）。抽到 `common.js` 是為了 Node 測試能直接 import（`fixed.js` 是 `mount` 模組，碰 DOM）。

- 月份迴圈從 `k = -1` 開始：上個月的事件可能順延進本月本週（例如 3/31 週日 → 4/1、4/1 當週就要列出）。`-1` 足夠：順延上限遠小於一個月，月營收（10 日）與台指期（第三週三）不會跨月，只有月底的財報截止會。
- 排序以順延後的 `date` 為鍵。

### D3 徽章

- 標記：`<span class="badge shifted" title="…">原 M/D</span>`，放在標題 `<b>` **之內**、行內排版跟著標題換行，「今天」徽章仍是列的 flex 子項。實作時 headless 274px 實測：徽章另占一個 flex 欄位會把標題擠成一字一行；放進標題內則窄寬度時換到標題下一行、寬版外觀不變。台指期的 `title`＝「依期交所規則順延至次一交易日」，財報與月營收＝「推定順延，以金管會公告為準」。
- 樣式：`.badge.shifted` 透明底、主題色細框與文字，比實心的「今天」徽章淡，兩者同列時可區分。
- 「今天」徽章加上 `today` class，`updateTimeSensitiveState()` 改以 `.badge.today` 找它——現行用 `.badge` 會抓到順延徽章並把它刪掉。
- 小工具視窗不取得焦點，`title` tooltip 不保證會出現；徽章文字本身必須自明，tooltip 只是附加說明、不列入驗收。
- 「下一次」清單的順延列同樣帶徽章。

### D4 資料訂閱與重建時機

`fixed.js` 讀 `ctx.snapshot`、訂閱 `ctx.onData`。取 `snap.status === 'ok'` 時 `snap.data.holidays`（陣列才採用、逐筆只留字串），否則空集合。收到資料時比對休市日集合的簽章（排序後 join），**有變才** `fullRender()`，沒變就不動（每 30 秒輪詢有變才推送，但其他鍵更新也會推送，不能每次都重建、打斷捲動）。

不顯示「尚無資料」：固定事件在沒有資料時仍可依週末算出正確的大部分內容，空著反而退步。

### D5 與 Lively 對照、版面

- `compare.mjs` 對 `fixed` 的對照已不成立（標籤與順延日期都刻意不同）。在 `panels.mjs` 的 `fixed` 條目加 `divergent` 說明，`compare.mjs` 遇到它時跳過並印出原因，不算失敗；本小工具的正確性改由 D2 的單元測試負責。
- 徽章讓列變寬。台股固定事件沒有收合斷點（標題在列內換行），但最小框寬是以最寬列實測的。實作後用 `measure-list-collapse.mjs` 以含徽章的情境重量；`min_width` 若變大，同步 `widgets.rs`、`list-collapse.test.mjs` 與量測報告。量測情境要選一個本週有順延列的日期（例如 2026-10-11）。

## Risks / Trade-offs

- [金管會臨時延長期限，或不延長而實際上不順延] → 徽章說明寫明推定、以公告為準；不宣稱為官方日期。
- [休市日清單只有當年度，跨年前後的 1、2 月事件（含春節）只依週末判斷] → spec 明訂此行為；1 月資料更新後自動修正。12 月看到的「下一次 2 月台指期結算」可能是未順延的日期。
- [交易日曆與行政辦公日不同的少數日子] → 推定範圍內，接受。
- [順延 30 天上限走到] → 回傳原日期、不顯示徽章，不丟錯；實務上不可能（休市清單最長連假約 9 天）。
- [對照測試不再覆蓋台股固定事件] → 單元測試覆蓋計算與分週；DOM 結構由實機目視確認一次。

## Migration Plan

純前端改動，隨下一版安裝檔與自動更新發佈；無設定檔或資料格式遷移。只改 `host/ui/**` 時須 `cargo clean --release -p fc-host` 再建置，前端才會重新嵌入（AGENTS.md「建置」）。回退＝還原 commit。
