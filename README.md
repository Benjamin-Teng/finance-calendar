# 財經日曆

桌面上的財經儀表板 — 總經日曆、台股事件、行情條，深色半透明外觀，資料每天自動更新。

這是常駐系統匣的桌面程式（桌面宿主 `fc-host`），把儀表板拆成時鐘、總經日曆、台股固定事件、台股動態事件、
行情條五個可各自開關、各自擺位的小工具，資料由程式內建抓取，不需要 Python、不需要 Lively。
舊的 Lively Wallpaper 版已停止維護、不再更新（見文末「舊版（Lively）已停止維護」）。

## 安裝

**需求**：Windows 10/11，x64 或 ARM64。**不需要系統管理員權限**，安裝在你自己的使用者資料夾。

1. 到 [Releases 的最新版](https://github.com/Benjamin-Teng/finance-calendar/releases/latest) 下載安裝檔：
   - 一般電腦（x64）：`finance-calendar-setup.exe`
   - ARM64 電腦（例如 Snapdragon 機種；在「設定 → 系統 → 關於」的「系統類型」看得到）：
     `finance-calendar-setup-arm64.exe`。**ARM64 電腦請裝 arm64 版**：裝了 x64 版會一直以模擬方式執行，
     而且之後的自動更新也會一直更新 x64 版。
2. 執行安裝檔。缺少 WebView2 執行階段時，安裝檔會自動下載安裝。
3. 安裝完成後程式自動啟動，出現在系統匣；之後每次登入 Windows 都會自動啟動（可在程式的設定視窗關掉）。

應用程式與功能清單與開始功能表裡的名稱都是「財經日曆」。

### 目前的安裝檔沒有程式碼簽章

安裝檔目前**沒有 Authenticode 程式碼簽章**（之後會申請程式碼簽章，申請與核准通過前不要期待這個警告消失），所以：

- **瀏覽器與 SmartScreen 會警告。** 瀏覽器下載時可能要你確認保留檔案；執行時 Windows 會顯示「Windows 已保護您的電腦」
  的警告，選「仍要執行」才能繼續（Microsoft 文件的英文名稱是「Windows protected your PC」與「Run anyway」）。依
  [Microsoft 文件](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)，
  未簽章的檔案每個新版本都要從零累積信譽，所以每次手動下載新版都可能再看到這個警告。
- **開了「智慧型應用程式控制」（Smart App Control）的電腦可能直接擋下，而且沒有「仍要執行」。** 依
  [Microsoft 支援文件](https://support.microsoft.com/en-us/topic/what-is-smart-app-control-285ea03d-fa88-4d56-882e-6698afdb7003)，
  應用程式未簽署時，智慧型應用程式控制會視為不受信任並封鎖，且目前無法針對單一應用程式略過；
  [Microsoft 文件](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)
  也說明它的簽章檢查適用於所有可執行檔，不只是從網路下載的檔案。若你的電腦開著這個功能而安裝被擋下，
  Microsoft 的說明是可在 Windows 安全性的設定中關閉它（關閉後的風險請自行評估）。另外，我們的建議是等有簽章的版本
  （之後會申請程式碼簽章）。
- 只從本專案的 GitHub Releases 下載安裝檔。每個 release 的說明裡附有安裝檔的 SHA256，可自行比對。

## 自動更新

- 程式啟動後約 1 至 3 分鐘會先檢查一次，之後每 6 小時檢查一次；沒有網路時靜默略過，下個週期再試。
- 找到新版後會在背景下載並驗證簽章（更新檔以程式內建的公鑰驗證，驗證不過就不會執行），
  然後在**系統匣跳出通知一次**，系統匣選單出現「**更新到 vX.Y.Z 並重新啟動**」，點它即可立刻更新。
- 沒有點也沒關係：**登入 Windows 後幾分鐘內會自動完成更新**（登入後 10 分鐘內找到並下載完新版時；超過就只通知、
  等你點選單）。平常使用中不會自己更新（更新時小工具會消失數秒）。
- 更新過程中小工具會短暫消失，桌布**不會**被還原為原本的桌布；新版啟動後小工具回到原位，設定與桌布主題都保留。
- 更新不需要系統管理員權限。自動更新下載的檔案不是由瀏覽器下載，預期不會再跳 SmartScreen 警告
  （這是依實作推論，尚待實機確認）。

### 手動下載新版覆蓋安裝

**一般請等自動更新，不需要自己下載新版。** 若你仍從 Releases 下載新版、在已安裝的電腦上直接執行安裝檔，安裝檔的
「重新安裝」頁預設選項是先解除舊版再安裝新版，照預設做的效果等同「解除安裝後重新安裝」：

- 桌布會先還原為原本的桌布，**桌布主題回到「不接管」，要在設定視窗重新選一次主題**；
- 開機自啟會重新開啟（就算你之前關掉了）；
- 設定與小工具位置會保留。

## 解除安裝

從 Windows 的「應用程式與功能」清單移除「財經日曆」：

- 解除安裝時會**先把桌布還原為原本的桌布**，再移除程式、開始功能表捷徑與開機自啟。原本的桌布若是 Windows 焦點（Spotlight），
  無法自動切回，請到 Windows 設定手動切回。
  有螢幕離線、只能先還原在線的螢幕時，解除安裝只寫記錄、照常繼續（離線那張螢幕之後若仍是財經日曆的圖，請到 Windows 設定自行
  更換桌布）。只有重試一次後仍然失敗（例如財經日曆一直沒有回應）才會跳出訊息，提醒桌布可能停在財經日曆的圖、需要自行更換；
  以被動（passive）或靜默（silent）模式解除安裝時不跳訊息。
- 你的設定與資料**預設會保留**（重新安裝後可繼續用）。
- 若在解除安裝畫面勾選「刪除應用程式資料」，因為程式的 WebView2 元件偶爾還握著檔案，**可能刪不乾淨**。
  可以在解除安裝完成、確認沒有 `msedgewebview2.exe` 殘留（或重新開機）後，手動刪除這兩個資料夾：
  - `%LOCALAPPDATA%\tw.fintools.fc-host`
  - `%APPDATA%\tw.fintools.fc-host`

## 功能

- **五個獨立小工具** — 時鐘・總經日曆・台股固定事件・台股動態事件・行情條，各自一個視窗、可在設定視窗各自開關；
  清單直接用滑鼠滾輪捲動。小工具是獨立的置底視窗，不嵌入 explorer 的視窗樹；全螢幕、鎖定時暫停動畫。
- **版面** — 每個螢幕的工作區切成 48×48 格線記錄位置與大小；從系統匣「編輯版面」拖曳移動、調整大小，放開對齊格線，
  重疊就彈回。多螢幕、不同縮放比例（DPI）的螢幕之間都能定位。
- **總經日曆** — Forex Factory（美國・歐元區・日本，中高重要性），含預測/前值，**跟隨系統時區**顯示。
- **台股動態事件** — **市值前百大財報公布日**・法說會・股東會（預告清單）＋處置股（當日制、遇休市順延），
  資料來自 MOPS／TWSE／TPEx；可在設定視窗加入除權息場次。
- **台股固定事件** — 台指期結算、季度期貨結算、財報與月營收公布截止，以**週日～週六**為一週單位列出本週場次。
- **行情條** — 13 檔紅漲綠跌跑馬燈：USD/TWD、美債 10Y、WTI、加權、台積電、日經 225、KOSPI、歐股 50、道瓊、S&P 500、
  NASDAQ、**費半（SOX）**、SOFR 3M。
- **動態桌布（可選）** — 五套主題（脊線・撕日曆・星盤・等高線・天際線）定時重畫，其中脊線、等高線、天際線依加權指數資料，
  撕日曆依休市日、融資與財報事件；每台螢幕依原生解析度設成 Windows 桌布。預設「不接管」；改回「不接管」或從系統匣「結束」時
  還原原本的桌布（Windows 焦點需自行切回）。
- **資料內建抓取** — 不需 Python、不需排程。台北時間每日 00・06・12・15・18 點抓取，程式啟動或睡眠恢復時錯過就補抓；
  單一來源失敗沿用上一份資料。設定視窗底部顯示資料來源與上次更新狀態。
- **外觀** — 深色半透明的純色背景與圓角，透明度與主題色可在設定視窗調整。
  （Windows 在小工具未取得焦點時不呈現毛玻璃模糊，所以設定裡的「毛玻璃」選項標示為不可用。）

資料來源：Forex Factory、MOPS 公開資訊觀測站（法人說明會一覽表）、TWSE／TPEx OpenAPI、Yahoo Finance chart API、
NY Fed SOFR。台灣沒有官方的「財報公布日」預告 API，故以 MOPS 法人說明會一覽表為準——法說會即台股實務上的財報公布場合。

## 舊版（Lively）已停止維護

舊版是 [Lively Wallpaper](https://www.rocksdanister.com/lively/) 桌布（`finance-calendar.html`＋以 Windows 排程跑
`update_tw_events.py` 抓資料）。它把桌布視窗掛進 explorer 的視窗樹，桌布行程被終止或卡住時會讓 explorer 被 Windows
重啟、桌布跟著消失，所以改寫成上面的桌面程式。舊版已凍結：**不再更新、不建議下載**，請改裝上面的安裝檔。

還在用舊版的人，建議先移除舊版再安裝新版，以免兩者同時出現在桌面：

1. 在舊版解壓的資料夾裡，對 `uninstall.bat` 按右鍵 →「以系統管理員身分執行」（或直接雙擊，按 UAC「是」）。它會：
   - 刪除資料更新排程「TW財經桌布資料更新」；
   - 詢問是否一併移除 Lively Wallpaper（預設不移除；移除 Lively 後它的桌布也會一起消失）；
   - 詢問是否一併移除 Python（預設不移除，只會移除以 winget 安裝的 `Python.Python.3.12`，其他程式可能也在用）。
2. 若保留 Lively，在 Lively 裡把 finance-calendar 這張桌布移除。
3. 舊版資料夾可直接手動刪除。

舊版資料夾裡沒有 `uninstall.bat` 時，以系統管理員身分開 PowerShell 執行
`Unregister-ScheduledTask -TaskName 'TW財經桌布資料更新' -Confirm:$false` 刪除排程（與 `uninstall.bat` 的第一步相同），
再依上面第 2、3 步處理。
